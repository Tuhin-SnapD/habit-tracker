# App icons

Tauri's dev mode (`npm run tauri:dev`) works without icons — it uses a default
placeholder. **For `tauri:build` to produce a `.exe` / `.dmg`, the files
referenced in `tauri.conf.json` must exist here.**

## One-shot generation

Drop a square PNG (at least 1024×1024) into the project root as `app-icon.png`,
then run:

```bash
npm run tauri:icon -- ./app-icon.png
```

This regenerates the whole `src-tauri/icons/` set (32x32, 128x128,
128x128@2x.png, icon.icns, icon.ico, plus all Windows tile variants).

## Manual list

If you'd rather generate icons by hand, the config expects:

- `32x32.png`
- `128x128.png`
- `128x128@2x.png` (256×256)
- `icon.icns` (macOS bundle)
- `icon.ico` (Windows binary)

Any extra tile sizes auto-generated by `tauri icon` are also fine — they're
unused when not referenced in `tauri.conf.json`.
